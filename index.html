⟡ Flow Necromancer — persistent force anchors

Tap artwork in Sculpt mode to place a force, or drag a glowing handle to reposition it. Each anchor persists and alters the actual 3D pigment and fiber flow. Six maximum to keep iPhone performance sane. Undo/Redo saves positions and their effects; Restart and New Design clear placed anchors.

⌁ Curve Witch — draw entire 3D forces

Select Draw Flow, then drag across the artwork to draw an invisible-depth 3D path. A bright trace shows where the permanent force is. Drag near an existing trace to move it, or tap it to change its behavior, width or intensity. Undo/Redo preserves curves and pigment; Restart/New Design clears paths. Use Touch Depth to choose the plane you draw in.

These are different divergence-free baseline flow laws—not merely new speeds. Switching a flow changes future transport without resetting existing pigment. Stir adds a local temporary impulse; Inject paints density; Orbit changes only the viewpoint.

✳ Fiber Nerves — directional material memory

Each voxel remembers a 3D strand direction and confidence. Flow shear bends those directions; accumulated coherence can resist cross-strand pigment transport. Turn this off on slower devices to avoid an extra 3D simulation pass; the existing directional memory remains available for lighting.

FILAMENT FORGE: Choose an evolving source architecture. Three colored 3D manifolds inject pigment into the live flow; source motion shifts the source itself while vortex advection bends its trails. Switching source or turning it off never erases existing dye. Growth is capped and thickness is measured in volume-world units, not screen pixels.
